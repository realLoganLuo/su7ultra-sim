# 驾驶物理修正与验证（2026-10-24）

## 修正内容

- 高速画面：120 Hz 物理状态在渲染帧之间插值，位置、姿态、转角、轮轴和轮转同步。追尾镜头先跟随车辆位移，再平滑相对偏移，避免帧时变化造成镜头跟随距离来回波动。道路采样改用双精度，降低高海拔微小高度差的量化噪声。
- 转向：A / D 或左右箭头是持续方向输入，松键回正，有转向速率限制及随速度降低的键盘转向幅度。以双轴侧偏力、横摆惯量、侧向速度推进轨迹，取消固定车道横移和自动沿路转弯。setLane 只供显式的自动测试驾驶员使用，仍经轮胎动力学执行。
- 制动：默认液压模型使用渐进压力建立、随轮载分配制动力、ABS 滑移调节。取消刻意迟缓、粗放的对照 ABS。S 约 0.28 秒建立全踏板需求，空格为全力脚刹；二者仍经过液压响应。纵横向轮胎力共享附着额度，停车后静摩擦保持，避免低速轮速抖动。
- 悬架：保留俯仰、侧倾、车身升降及四个非簧载轮轴。可视轮轴跟随物理状态，不再被硬贴到每个路面波纹；轮胎分离时不凭阻尼产生虚假接地力。取消为防止离地而修改坡顶几何和强制最低法向载荷的规则。
- 默认关闭原有 EMB / 全主动概念演示。1、2 键仍可打开，界面明确标为概念对照。尾翼使用固定角度，不再跟随刹车充当虚构空气刹车。
- 重置在原地完成悬架平衡，不再偷跑一段距离、降低传入车速。ABS 响应与控制状态一起清空。

## 数据与边界

[小米 SU7 Ultra 官方页面](https://www.xiaomiev.com/ultra)说明了 350 km/h 下最高 285 kg 下压力；该官网搜索摘要还列出双腔空气悬架；[小米官方介绍的搜索摘要](https://www.mi.com/global/discover/article?id=3768)给出 100–0 km/h 30.8 m 制动目标（该文章正文当前需 JavaScript）。下压力系数总和取 0.493 m²，在空气密度 1.2 kg/m³ 时与上述速度/载荷量级一致。并非所有速度都有 285 kg 下压力。

2300 kg、3 m 轴距和 1138 kW 保留项目已有基础参数。本次没有取得厂家轮胎曲线、质量惯量、制动压力曲线、阻尼图、真实 ABS / ESC 软件或实车传感器数据：干地摩擦系数 1.35、前后侧偏刚度、横摆惯量、压力时间常数、弹簧与阻尼均是估算，不能称为厂家标定或数字孪生。

默认悬架是有效弹簧/阻尼近似，并未实现量产空气悬架所有控制功能。赛道、碰撞与交通车仍是演示级近似。轮胎温度、磨损、湿地、热衰退、能量回收、完整 ESC / TCS、倒车和极端腾空姿态尚未完整建模；这些会影响极限工况，完成条件是补齐对应模型并取得可核验参数/实车数据。已有盘温显示只是估算，不代表经过验证的热衰退能力。原始车模为纽北外观资源，未替换成量产标准配置。未发现相关 TODO/FIXME 或 Mock 接口待接入。

## 验证

- `npm run build`：TypeScript 与 Vite 生产构建。
- `npm run test:driving`：有断言的回归，包括 5 / 20 / 100 / 200 / 300 / 350 km/h 方向短按与反打、左右对称、松键回正、静止转向不位移、制动渐进性、组合制动转向、重复重置、停车保持、30 / 60 / 144 / 165 Hz 插值、终点跨圈及变帧时追尾镜头。
- `npm run test:sim`：原有变道测试驾驶员、制动与 Flugplatz 场景，保留主动/被动对照数值输出；这些输出本身不代表实车验证。
- 平直干地全踏板模拟：100–0 为 30.12 m / 2.167 s；200–0 为 114.56 m / 4.158 s；300–0 为 245.88 m / 6.033 s。统计从制动输入开始，包括模型压力建立，不包括人的反应时间。所有轮胎在 10 m/s 以上无超过 80% 滑移的持续抱死。
- 在 300 km/h、40 / 100 Hz 交替帧时的追尾镜头复现中，旧代码稳态跟随距离波动约 0.030 m；新实现仅剩浮点误差。此项隔离镜头算法，不代表全场景 GPU 帧率或人眼体验测量。
- 本地浏览器通过实际按键完成 205–0 km/h 急刹，面板显示约 120 m / 4.25 s。已确认新控制说明、默认模式、真实车模和道路渲染。没有声称完成完整赛道人工试驾或真实车辆匹配验收。

使用：W 加速，A/D 持续转向（高速短按），S 渐进刹车，空格全力刹车，T 进入急刹路段，R 重置。松键仅让前轮回正，车身不会自动回到道路中心；弯道需要驾驶者转向。
